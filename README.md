# 🩸 Dead Frequency

Benvenuto nel repository ufficiale per il download e gli aggiornamenti di **Dead Frequency**!

Qui trovi sia il **Client & Launcher Ufficiale** (nativo ad altissime prestazioni in Rust / GPU), sia la **Resource Pack ufficiale** pronta all'uso per chi vuole giocare utilizzando il client standard di **Minecraft: Java Edition**.

---

## 🌐 Server Ufficiale
* **IP Server**: `liliumnetwork.com`
* **Versione consigliata**: `1.20.1` (o superiore)

---

## 🚀 Opzione 1: Launcher Ufficiale Dead Frequency (Consigliato)

Il launcher nativo per Windows con accelerazione GPU, rendering immediato e gestione automatica di aggiornamenti e pacchetti.

### 📥 Come iniziare:
1. Scarica **[DeadFrequency-Launcher-Windows.zip](https://github.com/gitcarlx/deadfrequency-download/releases/latest/download/DeadFrequency-Launcher-Windows.zip)** dalle Releases.
2. Estrai lo zip in una cartella a tuo piacimento sul computer.
3. Fai doppio clic su **`AVVIA-LAUNCHER.bat`** (o `dead-frequency-launcher.exe`).
4. Il launcher scaricherà automaticamente il client di gioco, la resource pack e si collegherà a **`liliumnetwork.com`**. Clicca su **Gioca**!

---

## ⛏️ Opzione 2: Giocare con Minecraft Standard + Resource Pack

Se preferisci utilizzare il normale Minecraft Launcher, Prism Launcher, Modrinth o Fabric/Iris:

### ⚡ Installazione Automatica con 1 Clic (Windows)
1. Scarica lo script **[`installa-resourcepack-minecraft.bat`](https://raw.githubusercontent.com/gitcarlx/deadfrequency-download/main/installa-resourcepack-minecraft.bat)** (o clicca destro -> Salva con nome).
2. Esegui il file `.bat`.
3. Lo script scarica l'ultima versione della pack, la posiziona in `%APPDATA%\.minecraft\resourcepacks\` e la attiva direttamente nel tuo gioco!
4. Avvia Minecraft, connettiti a `liliumnetwork.com` e sei pronto!

*(Per aggiornare la pack in futuro ti basterà eseguire **[`aggiorna-resourcepack-minecraft.bat`](https://raw.githubusercontent.com/gitcarlx/deadfrequency-download/main/aggiorna-resourcepack-minecraft.bat)**)*.

---

### 📦 Installazione Manuale Resource Pack
1. Scarica **[Phasmophobia-Pack.zip](https://github.com/gitcarlx/deadfrequency-download/releases/latest/download/Phasmophobia-Pack.zip)**.
2. Premi `Win + R`, digita `%APPDATA%\.minecraft\resourcepacks` e premi Invio.
3. Copia `Phasmophobia-Pack.zip` (o estrai la cartella) all'interno di questa directory.
4. Avvia Minecraft -> *Opzioni* -> *Pacchetti di risorse* -> sposta **Dead Frequency** tra i pacchetti attivi a destra.
5. Connettiti a `liliumnetwork.com`.

---

## 🛠️ Note e Aggiornamenti
Il sistema di aggiornamento automatico del launcher interroga `latest.json` ad ogni avvio per verificare la presenza di nuove patch del client o del texture pack, garantendo la piena sincronizzazione con il server.
