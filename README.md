# 🩸 Dead Frequency

Repository ufficiale per il download e gli aggiornamenti automatici di **Dead Frequency**.

Tutti i contenuti (il client di gioco ad alte prestazioni e il texture pack esclusivo) sono distribuiti e aggiornati in modo automatico dal **Launcher Ufficiale**.

---

## 🌐 Server Ufficiale
* **IP Server**: `liliumnetwork.com`

---

## 🚀 Come Giocare

1. Scarica **[DeadFrequency-Launcher-Windows.zip](https://github.com/gitcarlx/deadfrequency-download/releases/latest/download/DeadFrequency-Launcher-Windows.zip)** dalle Releases.
2. Estrai l'archivio sul tuo computer.
3. Esegui **`AVVIA-LAUNCHER.bat`** (o `dead-frequency-launcher.exe`).
4. Il launcher verificherà e scaricherà automaticamente il client di gioco, la resource pack sigillata e si connetterà al server.
5. Clicca su **Gioca**!
